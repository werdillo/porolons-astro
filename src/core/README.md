# core

Code with no subject: generic utilities. Logic only, no markup.

- `cn.ts`: `cn(...classes)`, a `clsx` wrapper used by the kit components.
- `seo/`: the search engine code, one box with its door: links (`absoluteUrl`, `alternateLinks`), structured data (`jsonLd`, `postalAddressLd`, `websiteLd`), `robotsTxt` and the sitemap's `sitemapI18n`. See its README.
