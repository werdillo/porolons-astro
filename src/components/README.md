# components

The UI kit: presentational pieces that know no business subject. Each component is a box with its door (`index.ts`).

- `accordion/`: collapsible sections (`Accordion`, `AccordionItem`, `AccordionTrigger`, `AccordionContent`).
- `container/`: the centered content column (`Container`).
- `dropdown/`: a click or keyboard menu (`Dropdown`, `DropdownTrigger`, `DropdownContent`, `DropdownItem`, `DropdownLabel`, `DropdownSeparator`).
- `section/`: a page section with its padding and background band (`Section`).
- `theme-toggle/`: the light and dark theme button (`ThemeToggle`).
- `typography/`: the type scale, nine styles H1-H6 and P1-P3 (`H1` … `P3`). See its README for the matrix; text sizes come only from here.
