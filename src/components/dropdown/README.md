# dropdown

A trigger button that opens a menu of items. `DropdownHandler.ts` holds the open state, `DropdownEvents.ts` binds the mouse and keyboard events, `DropdownMenu.ts` moves the focus through the items.

- `index.ts`: exports `Dropdown`, `DropdownTrigger`, `DropdownContent`, `DropdownItem`, `DropdownLabel`, `DropdownSeparator`.
